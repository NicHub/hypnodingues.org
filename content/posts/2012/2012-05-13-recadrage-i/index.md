<p>

Permet de revisiter certains événements du passé pour en modifier l’interprétation et les conséquences.
</p>

<ul>

<li>

Choisir un événement de la vie ayant laissé des traces (sans forcément savoir lesquelles).
</li>

<li>

Possibilité de faire cet exercice sans connaître le souvenir initialement, simplement en se basant sur des situations/sentiments récurrents.
</li>

</ul>

<ol>

<li>

Trouver dernier souvenir / dernière situation où le sentiment a été vécu.
</li>

<li>

Remonter le temps en utilisant ce sentiment afin de retrouver la première, ou l’une des premières fois où il a été ressenti.
</li>

<li>

Retrouver le souvenir bien nettement, se voir le vivre.
</li>

<li>

Déterminer ce qui aurait permis de vivre cet événement différemment (comportement, expérience, apprentissage, qualité, attitude, interprétation, etc. → vraiment agir sur soi)
</li>

<li>

Utilisation d’une fée ou d’un mage, qui permet d’apporter de nouvelles ressources.
</li>

<li>

Etre scénariste tandis que le double est l’acteur
</li>

<li>

Revisiter la scène avec les nouvelles ressources (comportement, interprétation, attitude).
</li>

<li>

Noter quelle différence cela apporte (1 à 10)
</li>

<li>

Une fois l’apprentissage suffisant, fusionner avec le double.
</li>

<li>

Remonter le cours du temps jusqu’à aujourd’hui en intégrant les changements.
</li>

</ol>
